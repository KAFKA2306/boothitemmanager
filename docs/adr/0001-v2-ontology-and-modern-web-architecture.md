# ADR-0001: 次世代改変エコシステム・オントロジーとモダンWebアーキテクチャへの昇格

## 📅 日付
2026-06-10

## 🚦 ステータス
承認済み (ACCEPTED)

## 📝 コンテキスト（背景だよぉ！）
これまでのアバター改変管理システムは、アバター名の単純なエイリアス（表記揺れ）管理にとどまっていたんだよ。でも、実際のアバター改変はもっと複雑で、以下のような課題があったの：
1.  **名前だけじゃ足りない！**: BOOTH IDでの一意な識別ができないと、本文中のリンクから情報を拾えないよ。
2.  **技術の進化についていけない！**: Modular Avatar (MA) や VRCFury、PhysBone 対応かどうかは、今の改変には必須の情報なのに、うまく検索できなかったんだ。
3.  **UIが重た〜い！**: 4万件を超えるアイテムを表示しようとすると、ブラウザの計算が追いつかなくてカクカクしちゃうことがあったよ。
4.  **画像が見えない！**: `pximg.net`（BOOTHの画像サーバー）が他サイトからのアクセスを拒否して、サムネイルがエラーになっちゃうことがあったの。

## 💡 決定事項（こうしたよぉ！✨）

### 1. オントロジー v2 への昇格 (`aliases.yml`)
単なるリストから「構造化された知識の基盤」に変えたよ！
-   **BOOTH ID 必須化**: すべてのベースアバターに `item_id` を付与。これで「本文にURLがある＝そのアバター対応」って確実に見抜けるようになったよ。
-   **多次元タグ体系**: 「機能（MA/PB）」「スタイル（地雷系/サイバー）」「構成要素（Mesh/Shader）」という、改変者に刺さる次元でタグを整理するようにしたよ。

### 2. モダンWebアーキテクチャへの破壊的刷新 (`index.html`)
フロントエンドを最新のウェブ標準に叩き直したよ！
-   **CSS Grid Areas**: 迷子になりやすい Flexbox のネストを捨てて、画面全体のレイアウトを一箇所で管理。
-   **Performance Isolation**: `.asset-card` に `content-visibility: auto` を適用。画面外のカードの描画をサボることで、**4万件あっても 60FPS** で動く快適さを手に入れたよ！
-   **Dynamic Metadata**: JavaScript に直書きしていたアバターリストを全削除。APIから動的に読み込むようにして、バックエンドとオントロジーを完全同期させたよ。
