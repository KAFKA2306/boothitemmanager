# 🌸 BoothItemManager2 のアイデンティティだょ！ 🌸

BOOTHのVRChatアセット（アバター、お洋服、小物、ギミック）を集めて整理し、とっても使いやすい検索と横断探索を提供するシステムだよぉ！(⑅•ᴗ•⑅)◜..°♡

## 🎀 コアアイデンティティ
- **目的**: 標準のBOOTH検索では難しい「色・スタイル・雰囲気」などの非構造タグ検索や、アバターごとの逆引き検索を提供するよ🍭
- **規模**: 約40,000件以上のデータをサクサク処理できるバッチパイプラインだよっ✨

## 🐾 メイン監査チェックリスト (Audit Checklist)
以下の基準をどれか1つでも満たさないと、監査で **REJECT（却下）** されちゃうから気をつけてね！

### 1. データの正しさ 🔍
- [ ] BOOTHの公開情報をクロールしていること
- [ ] 画像やタイトル、説明文を正しく扱っていること
- [ ] VRChat用のアイテムであることを判別できていること

### 2. パイプラインの完成度 ⚙️
- [ ] クローラーが正常に動いて生HTMLを保存していること
- [ ] ノーマライザがメタデータや対応アバターを正しく抽出していること
- [ ] 独自タグ（カラーやスタイル）を自動で付与できていること
- [ ] 検索用インデックス（search_index.json）を正しく構築していること

### 3. UIと探索の体験 🎨
- [ ] 複数のタグやカテゴリを混ぜて横断検索できること
- [ ] 特定のアバター対応アイテムを逆引きで絞り込めること
