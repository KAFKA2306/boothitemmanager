# BoothItemManager2 再現システム：完全監査・実装仕様

本システムは、BOOTHのVRChatアセットを収集・再構造化し、直感的な探索を可能にする「BoothItemManager2」の完全な再現を目指す検証・実装システムです。

## 1. コアアイデンティティ（BoothItemManager2の定義）
- **対象**: BOOTH公開のVRChat関連アセット（アバター、衣装、小物、ギミック）。
- **目的**: BOOTH標準検索を補完する「非構造タグ検索」と「横断探索」の提供。
- **データ規模**: 約42,000件規模を想定したスケーラブルなバッチ処理パイプライン。

## 2. 監査チェックリスト（機械的評価基準）
以下の項目をすべてパスしない限り、メインエージェントは **REJECT**（却下）と判定します。

### □ データソースの正当性
- [ ] BOOTH公開情報をクロールしているか
