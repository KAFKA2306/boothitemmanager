# 🌸 VRCFinderデータ品質比較 ＆ 改善命令だょ！ 🌸

VRCFinderのデータと比較して、私たちの分類ルールをアップデートするための改善命令書だよぉ！(⑅•ᴗ•⑅)◜..°♡

## 🎀 1. 検出された課題（カバレッジ不足の証拠）
VRCFinderと比較したところ、以下のカテゴリで分類漏れが見つかったの💦

1. **`ACCESSORY` カテゴリの分類漏れ** 💥
   - **問題**: VRCFinderと比べて、小物の分類数が大幅に不足していたよ。
   - **原因**: 「アクセサリ」や「小物」のエイリアス判定が狭く、`OUTFIT` や `ASSET`（その他）に流れていたの。
2. **`HAIRSTYLE` の分類漏れ** 💇‍♀️
   - **問題**: 髪型アイテムの抽出漏れがあったよ。
   - **原因**: 髪型関連のタグ（`Twin Tails`, `Short Hair`等）が正しく紐付いていなかったの。
3. **`TEXTURE` と `PROP` のカバー不足** 🎨
   - **問題**: テクスチャ（メイク、アイテクスチャ等）の分類が弱かったの。

## 🐾 2. 改善アクション命令（コマンドを実行してね！）
これらの問題を解決するために、以下のステップを実行するんだもん☆

1. **オントロジーの進化**:
   `scripts/evolve_ontology.py` を実行して、VRCFinderのタグセットから `appearances` や `HAIRSTYLE`, `ACCESSORY` の分類辞書を自動更新するよ！
2. **バルクパイプラインの再実行**:
   辞書を更新したら、`task build` を実行してカタログ全体のカテゴリとタグを再判定してねっ✨
3. **品質監査の実行**:
   最後に `task test` で、分類精度が目標値（F1-Score $\ge 0.98$）を満たしているか確認するの！
